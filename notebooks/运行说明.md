# GlycoAgentBench 运行说明

本文档用于说明项目的运行方式与常用命令。

## 1. 环境准备

建议使用 Python 3.12。

```bash
pip install -e .
```

如需开发依赖：

```bash
pip install -e ".[dev]"
```

## 2. API 配置（统一入口）

项目统一读取 `configs/api.yaml`：

```yaml
provider: openai_compatible
base_url: https://dashscope.aliyuncs.com/compatible-mode/v1
api_key: sk-xxxxxxxx
api_key_env: OPENAI_API_KEY
base_url_env: OPENAI_BASE_URL
model: qwen3.5-plus
```

说明：
- `api_key` 请替换为你的真实 key。
- `model` 可按需要替换（如 `qwen-plus`、`qwen3.5-plus`）。

## 3. 数据目录要求

每个数据集目录需要包含：

- `abundance.csv`
- `clr.csv`
- `sample_metadata.csv`
- `manifest.json`
- `hidden_truth.json`

示例最小数据集：`data/mock_demo`

## 4. 单模型运行（推荐先跑）

```bash
python -m src.app.run_single_model --model configs/models/mock.yaml --dataset data/mock_demo --api-config configs/api.yaml
```

使用 Qwen 配置：

```bash
python -m src.app.run_single_model --model configs/models/qwen.yaml --dataset data/mock_demo --api-config configs/api.yaml
```

## 5. 批量 benchmark

```bash
python -m src.app.run_benchmark --models-dir configs/models --benchmark-config configs/benchmark/default.yaml --api-config configs/api.yaml
```

## 6. 查看 leaderboard

```bash
python -m src.app.leaderboard --leaderboard outputs/leaderboards/leaderboard.csv
```

## 7. 输出结果说明

单次运行输出目录：

`outputs/runs/<timestamp>__<model>__<dataset>/`

关键文件：
- `plan.json`: LLM 输出的 workflow 计划
- `execution_trace.json`: 执行轨迹
- `tool_outputs/`: 每一步工具输出
- `metrics.json`: 指标结果
- `oracle.json`: Oracle 判定
- `report.json`: 汇总报告（机器可读）
- `report.html`: 汇总报告（人工查看）

批量运行输出：
- `outputs/leaderboards/leaderboard.csv`
- `outputs/reports/<benchmark_timestamp>/benchmark_summary.json`
- `outputs/reports/<benchmark_timestamp>/scenario_comparison.png`

## 8. 常见问题

### Q1: 报错 `missing API key env: OPENAI_API_KEY`

说明 API key 未生效。请检查：
- `configs/api.yaml` 中 `api_key` 是否已填写
- key 是否有效、未过期
- `api_key_env` 是否为 `OPENAI_API_KEY`

### Q2: 报错 401 `invalid_api_key`

说明 key 无效或权限不足。请在模型平台重新生成 key 后重试。

### Q3: 为什么 plan 里有些 `params` 是空的？

LLM 可能只输出工具顺序，不写参数。执行器会使用工具默认参数执行。
