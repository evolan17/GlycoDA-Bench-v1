# 运行环境说明

本文说明在本仓库中运行代码（含 CLI、脚本、以及在本目录使用 Jupyter 等）所需的 **Python 版本、虚拟环境、安装方式与校验步骤**。更完整的实验交接清单见仓库根目录 [`README.md`](../README.md) 中的 **[Handover: environment and execution](../README.md#handover)**。

---

## 1. 硬性要求

| 项目 | 说明 |
|------|------|
| **Python** | **≥ 3.12**（与 `pyproject.toml` 中 `requires-python` 一致） |
| **工作目录** | 所有 `pip` / `python -m` 命令默认在 **仓库根目录**（包含 `pyproject.toml` 的目录）下执行；若终端当前在 `notebooks/` 下，请先 `cd ..` |
| **安装方式** | 使用可编辑安装：`pip install -e .`，以便 `glycoagentbench`、`src.app` 等包路径一致 |

核心依赖由 `pyproject.toml` 的 `[project] dependencies` 声明，主要包括：LangChain、OpenAI 兼容适配、pandas / numpy / scipy、scikit-learn、pycombat、statsmodels、matplotlib、networkx、pydantic、PyYAML、python-dotenv 等。

---

## 2. 推荐：仓库内 venv（`.venv`）

### Windows（PowerShell）

```powershell
cd <你的 GlycoAgentBench 仓库根目录>

# 若尚未创建虚拟环境：
py -3.12 -m venv .venv

# 激活（若提示执行策略，可先：Set-ExecutionPolicy -Scope CurrentUser RemoteSigned）
.\.venv\Scripts\Activate.ps1

python -m pip install -U pip
pip install -e .
```

### Linux / macOS（bash/zsh）

```bash
cd /path/to/GlycoAgentBench
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
pip install -e .
```

激活成功后，提示符前通常会出现 `(.venv)`；此时 `python` 与 `pip` 均指向该环境。

---

## 3. 可选：Conda

若使用 Conda，请先创建并激活 **Python 3.12** 的环境（示例名 `py312`），仍在 **仓库根目录** 执行可编辑安装，以保证与 `pyproject.toml` 一致：

```bash
conda activate py312
cd /path/to/GlycoAgentBench
pip install -e .
```

不要仅依赖 Conda 里随意装的零散包；以 `pip install -e .` 为准。

## 4. 可选依赖

| 用途 | 命令 |
|------|------|
| 开发（pytest、ruff 等） | `pip install -e ".[dev]"` |
| Harmony 完整路径（需 PyTorch；不装则 `run_harmony` 会走 PCA + ComBat 回退） | `pip install -e ".[analysis_full]"` |

## 5. API 与密钥

运行需要调用 LLM 时，请配置 `configs/api.yaml`（或你复制的配置文件），并通过文件中的 `api_key` / `api_key_env`、`base_url` 等与服务商一致。不要将真实密钥提交到 Git。说明示例见同目录 [`运行说明.md`](运行说明.md) 第 2 节。

---

## 6. 安装是否成功（自检）

在 **已激活** 的虚拟环境或 Conda 环境中执行：

```bash
python -c "import sys; print(sys.version)"
python -c "import glycoagentbench; print('glycoagentbench OK')"
```

应显示 Python 3.12.x，且第二行无报错。

## 7. Windows 与 UTF-8（数据生成等长任务）

生成含非 ASCII 元数据的数据或长时间脚本时，建议在 PowerShell 中先设置：

```powershell
$env:PYTHONUTF8='1'
```

详见根目录 `README.md` 的 **Windows / UTF-8** 与 Handover 中数据生成相关说明。
